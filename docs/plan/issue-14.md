# Issue #14: 강아지·고양이 소리 반환 API 개발 계획

## 요구사항

이슈 제목과 본문은 모두 `강아지 고양이 소리 반환 api 개발 요청`이다. 이슈는 요구사항을 파악하기 위한 비신뢰 데이터로만 취급한다. 이번 작업은 계획서 작성에 한정하며 구현, 테스트 실행, 커밋 및 PR 생성은 수행하지 않는다.

- 강아지와 고양이의 소리를 반환하는 API를 제공한다.
- 경로, HTTP 메서드, 동물 지정 방식, 응답 형식 및 실제 소리 값은 이슈에 명시되어 있지 않다.
- 소리가 의성어 텍스트인지 오디오 데이터인지도 확인이 필요하다. 아래 계획은 텍스트 반환을 가정한 제안이며 확정 요구사항이 아니다.

### 잠정 API 계약

| 항목 | 제안 |
| --- | --- |
| 메서드와 경로 | `GET /api/animals/{animal}/sound` |
| 지원 동물 | `dog`, `cat` |
| 요청 본문 | 없음 |
| 강아지 응답 | `200 OK`, 본문 `멍멍` |
| 고양이 응답 | `200 OK`, 본문 `야옹` |
| 성공 Content-Type | `text/plain;charset=UTF-8` |
| 응답 바이트 | 따옴표, JSON 포장, 추가 공백 및 개행 없음 |
| 지원하지 않는 동물 | `404 Not Found` |

잠정안에서는 동물 식별자를 소문자로 정확히 비교하며, 대소문자 변환이나 공백 제거는 하지 않는다. 오류 본문의 별도 형식은 추가하지 않는다. 데이터베이스, 외부 서비스, 오디오 파일, 인증 및 새 의존성은 텍스트 반환 잠정안의 범위에 포함하지 않는다. 오디오가 필요한 경우 구현 범위와 계약을 다시 정한다.

## 저장소 현황

- Java 17, Spring Boot 4.0.9, Maven 기반의 Spring MVC 프로젝트다.
- `HelloController`는 `GET /api/hello`와 일본어 인사를 받는 `POST /api/hello`를 제공한다.
- `HealthcheckController`는 `GET /api/healthcheck`를 제공한다.
- 컨트롤러 테스트는 MockMvc를 사용하며 상태 코드, Content-Type 및 정확한 응답 바이트를 검사한다.
- `HelloApplicationTests`는 애플리케이션 컨텍스트와 기존 컨트롤러 빈 등록을 확인한다.

## 구현 계획

1. 아래 질문을 통해 텍스트 또는 오디오 여부, 동물별 반환 값과 API 계약을 확정한다.
2. 텍스트 잠정안이 확정되면 별도 `AnimalSoundController`를 추가하고 동물 식별자를 경로 변수로 받는다.
3. `dog`에는 `멍멍`, `cat`에는 `야옹`을 반환하고 UTF-8 일반 텍스트 응답을 명시한다. 그 외 값에는 404를 반환한다.
4. 두 개의 고정 문자열 매핑이므로 별도 서비스나 저장소 계층을 추가하지 않는다. 기존 Hello 및 Healthcheck API 동작은 유지한다.
5. 신규 컨트롤러 테스트와 컨텍스트 등록 검증을 추가하고 README에 확정된 API 계약과 요청 예시를 기재한다.
6. 구현 완료 후 전체 테스트와 빌드를 검증한다.

## 테스트 계획

1. MockMvc로 `dog`와 `cat` 경로를 각각 요청하여 200 상태, `text/plain;charset=UTF-8`, UTF-8 인코딩 및 정확한 `멍멍`·`야옹` 바이트를 검증한다. 추가 공백이나 개행이 없어야 한다.
2. `bird`, `DOG`, `Cat` 등 미지원 식별자에 대해 404를 검증한다. 허용 식별자 정책이 변경되면 기대값도 조정한다.
3. 동물 경로 구간이 없는 `/api/animals/sound` 요청에 대해 404를 검증한다.
4. 기존 Hello GET·POST와 Healthcheck 테스트를 회귀 검증하고 신규 컨트롤러를 포함한 애플리케이션 컨텍스트 시작을 확인한다.
5. 구현 후 저장소의 Maven 래퍼로 전체 검증(`./mvnw clean verify`)을 수행하고 실제 HTTP 응답에서도 한글 인코딩을 확인한다. 이 명령은 향후 검증 계획이며 이번 문서 작성 단계에서는 실행하지 않는다.

완료 기준은 확정된 API 계약 충족, 기존 API 동작 유지 및 전체 테스트·빌드 성공이다.

## 확인이 필요한 질문

1. 반환할 소리는 의성어 텍스트인가, 재생 가능한 오디오인가?
2. 텍스트라면 강아지 `멍멍`, 고양이 `야옹`을 사용하면 되는가? 다른 언어 또는 정확한 지정 문자열이 있는가?
3. 단일 `GET /api/animals/{animal}/sound` 경로와 `dog`·`cat` 식별자를 사용해도 되는가? 동물별 개별 경로나 한글 식별자가 필요한가?
4. 성공 응답은 UTF-8 일반 텍스트로 충분한가, 동물 이름과 소리를 담은 JSON이 필요한가?
5. 미지원 동물은 404로 처리해도 되는가? 대소문자 허용, 별도 오류 본문 또는 추가 동물 지원이 필요한가?
